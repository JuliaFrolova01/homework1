# Маскировка номера счета или карты
## Описание 
Маскировка номера счета или карты - это веб-приложение на Python, которое позволяет создавать маски 

## Установка
1. Убедитесь, что установлен Python версии 3.13.2
2. Клонируйте репозиторий: 
https://github.com/JuliaFrolova01/homework1/pull/1
3. Установите зависимости: 
pip install -r requirements.txt

## Тесты
1. Все тесты находятся в папке tests
2. Чтобы запустить тестирование, необходимо в терминале ввести команду pytest
3. Покрытие тестами составляет 98%
